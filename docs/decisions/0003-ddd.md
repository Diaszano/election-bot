# ADR 0003: Use cohesive domain concepts

Status: accepted. Date: 2026-10-10.

## Context

The approved election-bot specification requires a maintainable single-election modular monolith with durable Telegram recovery.

## Decision

Election snapshots own invariants, canonical comparison, timestamp precedence and milestones. Subscription and notification packages represent actual lifecycle/delivery state.

## Consequences

Avoid unused entities and generic repositories.

See [architecture](../architecture.md) and [specification](../superpowers/specs/2026-10-10-election-bot-design.md).
